## 动机

小丸工具箱已停止更新，也不再支持 H.265 或 AV1 编码。为了方便地压制 osu! 背景视频，我开发了这个工具。

本项目是一个 FFmpeg 前端，主要用于满足个人的视频压制需求。相同的操作也可以通过命令行完成；如果需要更多视频压制功能，可以使用其他开源 FFmpeg 前端。

**注意：** 本项目完全通过 vibe coding 方式开发，质量不作保证，仅供娱乐使用。

## 功能

- 支持 **2-Pass VBR** 和 **CRF** 两种编码模式。
- 实时显示编码进度，包括完成百分比、已用时间和预计剩余时间。
- 支持自定义输出分辨率和缩放。
- 支持三种音频模式：不输出音频、复制音频流、转码音频（AAC 或 FLAC）。
- 提供视频预览功能，支持播放、逐帧查看和定位；可将当前画面设为裁剪起点或终点。
- 支持按帧号或时间指定视频裁剪范围，详见[视频裁剪](#视频裁剪)。
- 支持单独提取音轨，导出文件保持源音轨的编码，详见[提取音轨](#提取音轨)。
- 支持中文和英文界面。
- 支持记录和导出详细编码日志。
- 支持拖放视频文件进行输入。

## 下载与安装

### 前置要求

将以下文件放入与 `x264video4osu.exe` 同级的 `tools` 目录：

- `ffmpeg.exe`：从 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载包含 x264 的 GPL 版本。
- `libmpv-2.dll`（可选，仅用于视频预览）：从 [zhongfly 的 mpv Windows 构建](https://github.com/zhongfly/mpv-winbuild/releases) 下载 `mpv-dev-lgpl-x86_64-*.7z`。选 LGPL 版，和本项目的 MIT 许可证不冲突。

**注意：** Release 版本已包含上述两个文件。只有从源码自行编译时，才需要手动准备这些文件。

文件准备完成后，运行 `x264video4osu.exe`。具体操作参见[使用方法](#使用方法)。

## 编码模式与推荐配置

默认使用 **CRF**（恒定质量）模式，通常更便于使用。如果谱面对视频文件大小有严格限制，可以改用 **2-Pass VBR**，这样能更精确地控制输出体积。

两种编码模式的原理、CRF 取值参考、文件大小估算、osu! 背景视频的推荐参数，以及程序使用的 x264 参数，详见 Wiki：[编码模式、推荐配置与技术参数](wiki/Home.zh-CN.md)。

## 使用方法

### 基本操作流程

1. **选择输入视频**
   - 点击“浏览”按钮选择视频文件。
   - 或将视频文件直接拖放到程序窗口中。

2. **选择输出格式**
   - 推荐使用 `flv` 或 `avi`。osu! stable 存在一个已知问题：使用 MP4 作为背景视频可能导致游戏随机崩溃，详见[相关讨论](https://osu.ppy.sh/community/forums/topics/1976015?n=1)。

3. **设置输出路径（可选）**
   - 如果未指定输出路径，程序会在输入文件所在目录生成 `{原文件名}_output.flv` 文件；文件扩展名会根据所选输出格式调整。

4. **配置编码参数**

   | 参数 | 说明 |
   | --- | --- |
   | **输出格式** | 支持 `flv`、`avi` 和 `mp4`。 |
   | **编码方法** | 选择 `2-Pass VBR` 或 `CRF` 模式。 |
   | **数值框** | 在 2-Pass VBR 模式下表示比特率，在 CRF 模式下表示质量值。 |
   | **分辨率** | 按“宽 × 高”设置输出分辨率；设为 `0` 表示保持原值。 |
   | **Scale Up** | 是否允许放大视频，默认关闭。 |
   | **音频模式** | 不输出音频（默认）、复制音频流，或转码为 AAC / FLAC；FLAC 仅适用于 MP4。 |
   | **裁剪视频** | 启用后可指定视频起止范围，支持按帧号或时间裁剪，详见[视频裁剪](#视频裁剪)。 |
   | **提取音轨** | 将音轨单独导出为一个文件，详见[提取音轨](#提取音轨)。 |

5. **开始编码**
   - 点击“开始”启动编码。

6. **查看进度**
   - 主界面显示实时编码进度。
   - 在“Log”标签页中查看详细日志。

7. **查看处理结果**
   - 编码完成后，程序会显示输出文件大小。
   - 点击“打开输出文件夹”可打开输出目录。

### 视频裁剪

启用“裁剪视频”后，程序会裁剪并编码所选的片段。

#### 设置裁剪范围

| 控件 | 说明 |
| --- | --- |
| **裁剪单位** | 可选择“帧”或“时间”。选择“时间”时，支持 `时:分:秒.毫秒` 格式，例如 `0:01:23.500`；也支持 `分:秒` 和纯秒数格式。 |
| **起点 / 终点** | 根据所选单位填写帧号或时间戳。 |

切换“裁剪单位”时，程序会自动将已填写的起止值换算为新单位，无需手动计算。换算时需要使用源视频的帧率，程序会自动读取。

#### 使用预览定位

程序窗口右侧边缘的竖条用于展开视频预览面板。打开面板后，可以拖动进度条，或在帧号框、时间戳框中输入位置，再点击“跳转”定位。

定位裁剪范围时：

- 点击“设为开头”，将当前画面对应的位置设为裁剪起点。
- 点击“设为结尾”，将当前画面对应的位置设为裁剪终点。

#### 快捷键

以下快捷键仅在焦点不处于输入框时生效：

| 快捷键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `D` / `F` | 逐帧查看 |
| `←` / `→` | 向前 / 向后跳转 5 秒 |
| `Ctrl` + 方向键 | 向前 / 向后跳转 30 秒 |
| `Shift` + 方向键 | 向前 / 向后跳转 1 分钟 |
| `Home` / `End` | 跳转到视频开头 / 结尾 |
| `[` / `]` | 将当前位置设为裁剪起点 / 终点 |
| `↑` / `↓` | 调高 / 调低音量 |
| `M` | 静音 / 取消静音 |

#### 注意事项

- 按帧裁剪需要成功读取源视频的帧率。如果无法读取，程序会提示改用按时间裁剪；少数可变帧率视频可能出现这种情况。

### 提取音轨

点击“提取音轨”后，程序会把源文件里的音轨单独导出成一个音频文件，音质和源文件完全一致。

音频的保存位置与视频输出一致，文件名形如 `名字_audio.ogg`。

如果启用了“裁剪视频”，导出的音频也会限制在所设裁剪区间内。

### 日志功能

- 点击“保存日志”按钮可保存完整日志。
- 日志文件名格式为 `log_yyyyMMddHHmmss_随机数.txt`。

### 语言切换

使用窗口底部右侧的“语言”下拉框，可在中文和 English 界面之间切换。切换后立即生效。

## 开发说明

### 技术栈

- Rust（edition 2021）
- Slint 1.17.1：UI 框架，采用 Fluent 风格，使用 winit 后端
- femtovg：OpenGL 渲染器；项目通过本地 patch 修正 DPI 缩放时的抗锯齿问题
- FFmpeg：通过命令行调用

### 构建

```bash
cargo build --release
cargo test
```

构建需要安装包含 `x86_64-pc-windows-msvc` 目标的 Rust 工具链。Release 构建通过 `.cargo/config.toml` 静态链接 CRT，生成的 EXE 不依赖外部 CRT 运行库。
